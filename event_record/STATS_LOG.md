## Sat Nov 14 10:35 ET - start
- stats/.venv built with uv (CPython 3.12.8). Pinned: numpy 2.5.4, scipy 1.18.1, pandas 3.1.1, pymannkendall 1.4.3 (test oracle only, never imported by trendtrial), pytest 9.2.0. See stats/requirements.txt.
- Design decisions, recorded before any result:
  1. Ladder grain: per-cell series is the seasonal mean per year (n = number of seasons, 25 or 45), the same grain as the regional test and the validation. Consequence, stated honestly: with complete months, anomalies against a per-cell same-season climatology only shift the series by a constant, and MK and Sen are invariant to that. Rung 2 therefore changes a cell only where months are missing (the seasonal mean then mixes different months and the anomaly mean does not). The bundle reports how many cells rung 2 changed; the UI should say "rung 2 changed nothing here" when that is 0.
  2. Missing years: MK and Sen use valid years only, Sen uses calendar-year differences; Hamed-Rao counts lags in valid-observation order (as pymannkendall skips NaN). Approximation stated in the bundle.
  3. Hamed-Rao factor floored at 1 (spec 3.3); pymannkendall does not floor, so the oracle test compares the unfloored factor.
  4. Regional series: anomalies per cell against own per-cell, per-calendar-month climatology over the claim period; cos-lat weighted mean of anomalies per month; a region-month is valid only if at least 80% (parameter) of support cells with a valid climatology have a valid anomaly; a season is valid only if at least 2/3 (parameter) of its months are valid.
  5. Uncertainty: residual moving-block bootstrap around the Sen line (block length default 3, 2000 reps, seed fixed); slope interval = percentile 2.5/97.5 of bootstrap Sen slopes; chart band = pointwise percentile 2.5/97.5 of the bootstrap Sen lines. Same draws for both. Raw trending values are never resampled. Gap years: residuals are resampled among valid years and placed on valid years.

## Sat Nov 14 10:37 ET - oracle first run: two findings, rules revised BEFORE the re-run (numeric tolerances unchanged)
First run of tests/test_oracle.py (10:36): BH 50/50 pass, MK S/var/z/p/slope pass, 2 failures:
1. Intercept: pymannkendall uses the Kendall-Theil intercept median(x) - slope*median(t); mine was median(x - slope*t). Fixed to pymannkendall's definition (a definition choice, not a bug).
2. Hamed-Rao variance differed on 52 of 300 series. Diagnosis: in every inspected case the Sen-detrended residuals contain exact mathematical ties (the median-slope pair when the number of pairs is odd; rounded/tied data), whose float rounding in pymannkendall (x - arange(1,n+1)*slope) decides whether they rank as ties. The ranking, and so the factor, then depends on rounding luck. Shipped fix: residuals are rounded to 1e-9 of the series scale before ranking so exact ties are always treated as ties (average ranks).
Revised oracle rule (recorded before the re-run): the exact HR comparison (rel 1e-9 on the unfloored variance) applies to series whose sorted detrended residuals have no gap below 1e-9 of the series scale; series with such near-ties are counted and reported, and for them a separate test requires the shipped result to be invariant to a 1e-12 relative perturbation of the input (tie robustness). MK comparisons and BH comparisons stay on all series.

## Sat Nov 14 10:41 ET - WP3 validation design and PASS BARS, recorded BEFORE the validation run
Scenarios (all synthetic, shipped method only: seasonal-mean series, MK + Hamed-Rao, Sen slope, residual block bootstrap length 3 with 2000 reps, BH q = 0.10 on rung-3 p):
- Regional (one series): null AR(1) phi in {0, 0.3, 0.6} with normal noise, at n in {23, 25, 45} (the lengths of the claim periods; 25 is the short-sample case); skewed null (centred exponential noise, phi 0.3, n = 25); null with gaps (12 percent of years missing at random, phi 0.3, n = 25); positive trend (0.3 noise SD per decade) at phi in {0, 0.3, 0.6}, n = 25 and 45.
- Cells (400-cell field, noise smoothed over about 2 cells so cells are correlated, AR(1) in time, n = 25): global null at phi in {0, 0.3, 0.6}; mixed truth with 30 percent of cells carrying a true trend of 0.3 to 0.6 SD per decade, all positive; mixed-sign truth (half of the true cells negative).
Measures, each with Monte Carlo SE: regional test size (HR) plus MK-independent and OLS size for context; power; Sen bias (mean slope error in SD per decade, with SE); interval coverage of the true slope for the bootstrap interval (shipped) and the analytic Hamed-Rao Sen interval (context); BH empirical FDR (mean false discovery proportion, 0 when nothing flagged, SE = sd/sqrt(fields)); probability of any BH rejection under the global null; per-cell size at rungs 1 and 3; cell power.
Replicate floors: regional size 4000 sims per scenario (SE about 0.0034); coverage and bias 1000 sims per scenario with the full 2000 bootstrap reps (SE about 0.007); cell scenarios 200 fields. Below the floor the dependent verdict is disabled, not shipped.
PASS BARS (fixed now, never retuned after results):
- B1 regional size (HR, null scenarios): within 0.05 +/- 2 SE. Failure above the band (test too liberal) DISABLES the regional verdict for claims governed by that scenario. Failure below the band (test too conservative) is published and shown to the user as a flag but does not disable the verdict (it costs power, not correctness).
- B2 FDR at q = 0.10: empirical FDR <= 0.10 + 2 SE in the mixed-truth and mixed-sign scenarios, and P(any rejection) <= 0.10 + 2 SE under the global null. Failure DISABLES the cell map flags, hotspot counts and the breadth conditions of the verdict (cells_enabled = false).
- B3 interval coverage of the true slope for a nominal 95 percent bootstrap interval: >= 0.90 (null and trend scenarios). Failure DISABLES the slope interval and the chart band (interval_enabled = false); the verdict can then not be "supported".
- B4 Sen bias: |mean bias| <= 2 SE (null-trend scenarios with symmetric noise and the skewed scenario; trend scenarios use the same rule relative to the true slope).
Governing scenario for a claim: n = the tested n closest to the claim's number of seasons; phi = the smallest tested phi not below the claim's detrended lag-1 autocorrelation of the regional series (a claim above phi 0.6 gets no governing scenario and everything is disabled); gaps scenario added if the claim's regional series has gap years; skewed scenario added if the absolute skewness of the regional series exceeds 0.8. A claim is enabled only if ALL its governing scenarios pass the relevant bars (regional verdict: B1 anti-conservative side + B4; interval: B3; cells: B2).

## Sat Nov 14 11:01 ET - WP0 METHOD ADDENDUM 2 (requested by the orchestrator, to be countersigned): corrected regional and cell tests, rules recorded BEFORE the candidate run and before any claim result is looked at
Reason: the registered regional test (MK + Hamed-Rao with significance-screened lags) was found too liberal when the series has persistence (dev run 10:46 and the final run A, see above). A product where every persistent claim says "no verdict" would fail the brief, so candidate corrections are measured on synthetic data only, and one is chosen by a rule fixed here.
Candidates (all two-sided at 0.05, Sen slope unchanged, gaps handled by compacting valid years as before):
- C1 mk_independent: raw MK (the first rung, context).
- C2 hr_registered: the registered Hamed-Rao (screened lags), factor floored at 1.
- C3 hr_all_lags: Hamed-Rao WITHOUT screening: all rank-autocorrelation lags 1..floor(n/3), factor floored at 1.
- C4 yue_wang: Yue and Wang (2004) effective sample size from lag-1 AR: factor = 1 + 2 * sum_{k=1}^{n-1} (1 - k/n) * r1^k, with r1 the lag-1 autocorrelation of the Sen-detrended DATA (not ranks); factor floored at 1; r1 capped at 0.95.
- C5 tfpw: trend-free pre-whitening (Yue et al. 2002): r1 of the Sen-detrended data, whiten (x'_t - r1 x'_{t-1}), add the trend back, ordinary MK (independent variance) on the result; always applied (no screening); r1 clipped to [-0.95, 0.95].
- C6 boot_mk_L3 and C7 boot_mk_L5: moving-block bootstrap MK p-value: Sen-detrended residuals (centred), block length 3 or 5, 499 resamples; p = (1 + #{|S*| >= |S_obs|}) / (1 + 499), S_obs from the data, S* from the resampled residual series.
Evaluation: normal noise, AR(1) phi in {0, 0.1, 0.2, 0.3, 0.45, 0.6}, n in {23, 25, 45}: size under the null (batched candidates C1-C5: 4000 simulations, bootstrap candidates: 2000) and power under a trend of 0.3 SD per decade (same counts), each with Monte Carlo SE. Also the gaps (12 percent of years missing, phi 0.3, n 25) and skewed-noise (phi 0.3, n 25) nulls for every candidate.
SELECTION RULE for a claim (fixed now): governing scenarios exactly as before (n nearest tested, phi = the smallest tested phi not below the claim's detrended lag-1 autocorrelation, plus gaps and skew scenarios if they apply). A candidate PASSES if its null size is not above 0.05 + 2 SE in every governing null scenario (too conservative is flagged, not failing). The SHIPPED regional test is the passing candidate with the highest power in the governing trend scenario (ties within 0.5 SE go to the earlier candidate in the list above). Raw MK and the registered Hamed-Rao stay visible on the ladder as rungs whatever is shipped. If no candidate passes, the regional verdict is disabled as before.
CELLS: per-cell rung 3 uses the batched candidate (C2 to C5; bootstrap candidates are regional only) with the highest BH power among those whose BH false-discovery rate is <= 0.10 + 2 SE in all three truths (global null: P(any rejection) <= 0.10 + 2 SE) at the governing phi, measured on the same 400-cell correlated fields (200 fields). If none qualifies, cells_mode = unadjusted_descriptive: the map shows cells with p < 0.05 under the best-size batched candidate as DESCRIPTIVE and UNADJUSTED, with no false-discovery claim, and the verdict does not use the map.
INTERVAL: unchanged rule (bootstrap if B3 passes, else analytic HR Sen interval if B3a passes, else none). The interval and the chart band remain separate from the test choice.
