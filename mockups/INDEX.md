# H18 mockups: five hero-screen directions (light + dark each)

Concept, not product. All numbers are fake. Hero screen = trial view for claim C-A at rung 3 of 4: claim statement, four-rung ladder with flagged-area fractions, per-cell map, regional anomaly chart with band and Sen slope per decade, verdict card ("Evidence-limited"). Generated by Codex CLI (five parallel runs, prompts in `prompts/`), then screenshotted at 1440x900 with headless Chrome. Each HTML file is self-contained (no external requests), follows `?theme=light|dark` and the system setting, and has a working toggle. Small defects Codex left were fixed by hand: chart-axis fill (black triangle) in option 3, and the "concept, not product" chip overlapping footer text (option 2) or the verdict card edge (option 5).
