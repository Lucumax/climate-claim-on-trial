Climate Claim on Trial is an independent entry in the NASA Space Apps Challenge. It is not endorsed by NASA. It uses public NASA Earth data products and does not use NASA logos.

We run no server of our own, and no AI model runs on this page. Case files are archived runs, computed in advance and read from data bundles. Investigate reads a precomputed library of NASA satellite and model data and fetches NASA POWER data live. It computes results in your browser.
